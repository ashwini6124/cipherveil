## Overview
CipherVeil is a final-year engineering project that explores agentic AI-driven steganography techniques to hide information securely within digital media.

## Project structure
- src/ - Python source code and AI components
- web/ - Frontend (HTML/CSS) for demos and visualization

## Setup
1. Clone the repo:

   git clone https://github.com/yamini1508/cipherveil.git
2. Create a virtual environment and install dependencies (example):

   python -m venv venv
   source venv/bin/activate  # macOS/Linux
   venv\Scripts\activate     # Windows
   pip install -r requirements.txt

## Usage
- Implement AI/steganography code inside `src/` and use `web/` for any frontend demonstration.
